# Clipped

## Author
Sahithi Mothe

## Description
This project focuses on generating and analyzing sine waves, along with playing the generated audio using Python. 
The objective is to create audio files featuring both standard sine waves and clipped sine waves, examine their audio properties, and play them directly.

## What I did
- Implemented sine wave generation and analysis successfully.
- Matched the generated waveforms with the provided WAV form from the assignment on Canvas.
- Enabled audio playback using the sounddevice library.
- Created two audio files: "sine.wav" and "clipped.wav".
- Conducted analysis on the properties of the generated WAV files.
