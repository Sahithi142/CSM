# Pop Music Generator

## Author

Sahithi Mothe

## Description

This project is to generate rhythmic and melodic music patterns using Python. It includes waveform generation, rhythm creation, and combining melodies and basslines. The music can be played directly or exported as audio files.

## What I Did

- Implemented waveform generation for sine, square, sawtooth, and triangle waveforms.
- Developed rhythm patterns with kick, snare, and hi-hat sounds.
- Synthesized melodic loops and basslines with customizable parameters.
- Enabled audio playback using the sounddevice library.
- Implemented a way to save the music as WAV files.
